03 · Algoritmo
Persona 2
Algoritmo seleccionado

Kahn construye un orden topológico

La regla es sencilla: procesar primero las materias con grado de entrada 0 y liberar progresivamente las que dependen de ellas.

1

Calcular grados

Contamos cuántos prerrequisitos tiene cada materia.

2

Crear la cola

Entrarán las materias cuyo grado de entrada sea 0.

3

Procesar

Quitamos una materia y reducimos los grados de sus dependientes.

4

Verificar

Si procesamos todas las materias no existe ningún ciclo.

Idea clave

Una materia se vuelve disponible exactamente cuando su grado de entrada llega a cero.

05 · Implementación
Persona 3
Código en Python

La implementación sigue los mismos pasos

from collections import deque

def organizar_pensum(materias, prerrequisitos):
    grafo = {m: [] for m in materias}
    grado = {m: 0 for m in materias}

    for requisito, materia in prerrequisitos:
        grafo[requisito].append(materia)
        grado[materia] += 1

    cola = deque([m for m in materias
                  if grado[m] == 0])
    orden = []

    while cola:
        materia = cola.popleft()
        orden.append(materia)

        for siguiente in grafo[materia]:
            grado[siguiente] -= 1
            if grado[siguiente] == 0:
                cola.append(siguiente)

    return orden if len(orden) == len(materias) else None
