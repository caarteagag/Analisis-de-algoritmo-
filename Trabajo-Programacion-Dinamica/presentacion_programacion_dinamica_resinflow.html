02 · ¿Por qué DP?
Persona 1
Idea central

El problema grande se apoya en respuestas óptimas de problemas más pequeños

Estado
dp[x] = mínimo número de envases para formar exactamente x ml
Subproblema

¿Cuál es la mejor forma de completar un volumen menor?

Solapamiento

Los mismos valores como dp[100] pueden aparecer desde decisiones distintas.

Memoria

Calculamos cada estado una sola vez y reutilizamos su resultado.

Objetivo final

La respuesta buscada será dp[600].

03 · Recurrencia
Persona 2
Cómo se conectan los estados

Probar un envase y aprovechar la mejor respuesta que ya conocemos

Relación de recurrencia
dp[x] = min( dp[x], dp[x - v] + 1 )

Para cada volumen x probamos cada tamaño v. Si el estado x - v ya podía formarse entonces usar un envase de tamaño v produce una nueva solución candidata.

Ejemplo para 600 ml

v = 300 → miramos dp[300] + 1. Como dp[300] = 1 entonces obtenemos 2 envases para 600 ml.

Caso base
dp[0] = 0

Para formar 0 ml no necesitamos ningún envase.

Inicialización
dp[x] = ∞

Los demás volúmenes comienzan como imposibles hasta demostrar lo contrario.

Respuesta imposible

Si dp[objetivo] sigue en ∞ al terminar entonces no existe una combinación exacta.

05 · Por qué funciona
Persona 2
Propiedad óptima y costo

Cada decisión consulta una respuesta óptima ya calculada

1

Solución óptima por subproblema

Cuando calculamos dp[x] comparamos todas las posibles últimas elecciones de envase.

2

No repetimos trabajo

dp[x - v] ya está calculado y se reutiliza en lugar de resolverlo de nuevo.

3

Elegimos el mínimo

La función min conserva la mejor alternativa encontrada para cada volumen.

No acotada

Los tamaños pueden reutilizarse ilimitadamente por eso un mismo envase puede formar parte de muchos estados sucesivos.

O(A · k)
Tiempo

A = volumen objetivo · k = tamaños disponibles.

O(A)
Espacio

Solo guardamos la tabla dp.

¿Por qué no greedy?

Greedy toma una decisión local. DP compara todas las últimas elecciones posibles y conserva la mejor respuesta global para cada estado.

06 · Implementación
Persona 3
Código en Python

El código sigue exactamente la definición del estado y la recurrencia

def min_envases(tamanos, objetivo):
    INF = objetivo + 1
    dp = [INF] * (objetivo + 1)
    eleccion = [-1] * (objetivo + 1)

    dp[0] = 0                 # caso base

    for x in range(1, objetivo + 1):
        for v in tamanos:
            if v <= x and dp[x - v] != INF:
                candidato = dp[x - v] + 1
                if candidato < dp[x]:
                    dp[x] = candidato
                    eleccion[x] = v

    if dp[objetivo] == INF:
        return None

    combinacion = []
    x = objetivo
    while x > 0:
        combinacion.append(eleccion[x])
        x -= eleccion[x]

    return dp[objetivo], combinacion
Estado

dp[x] guarda la mejor respuesta conocida para x ml.

Recurrencia

El candidato es dp[x - v] + 1.

Reconstrucción

eleccion[x] permite recuperar qué envases forman la solución.

Imposible

Si dp[objetivo] sigue en INF retornamos None.

Combinar capacidades discretas para completar un pedido exacto con la menor cantidad de contenedores.

estado + decisión + recurrencia
